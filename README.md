# DanalTech Rentals (DTR)
> Rent smart. Work better. Zero stress.

A web-based equipment rental management system 
built with PHP, MySQL, Bootstrap 5 and custom CSS.
Developed as coursework for CMM007 — Intranet 
Systems Development at Robert Gordon University.

## Tech Stack
- PHP, MySQL, XAMPP
- Bootstrap 5, Custom CSS, JavaScript

## Features
- Role-based login (Admin / User)
- Equipment and user management (CRUD)
- Rent and return system
- Cart system with per-day pricing
- Light/dark theme toggle
- Security — CSRF, XSS, SQL injection prevention

## Setup
1. Clone repo into XAMPP htdocs
2. Create database: danaltech_rentals
3. Run schema SQL in phpMyAdmin
4. Visit http://localhost/danaltech_wrentals/
